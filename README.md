# Portfolio Manager V2.3

米国個別株のコア・サテライト運用向けに、実保有と円・ドル現金から目標配分への売買計画を試算します。保有数量・取得原価と価格データを別々に管理し、実保有、目標配分、株価、為替の確認がそろうとシミュレーションを表示します。

## 起動

リポジトリのファイルを一式取得し、ルートで次を実行します。ブラウザーで `http://127.0.0.1:4173/portfolio_manager.html` を開きます。アプリの実行に Node.js やパッケージの取得は不要です。

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

同じブラウザーの同じオリジンで旧版を使用していた場合は「データ管理・取得設定」→「旧ブラウザーデータを確認」で移行できます。別オリジン、別ブラウザー、別端末の場合は元のブラウザーや旧保存先から取得した JSON を選択してください。旧版と同じファイル URL で使う場合も、アプリの関連ファイルが同じ相対配置にある状態で開きます。旧ファイル URL の保存領域やファイルアクセス権限はブラウザーの実装に依存します。

## 最初の設定

1. 「データ管理・取得設定」で旧データを確認するか「ロットを登録」から新規登録します。移行候補の「要確認」を資産区分に変更し、米国個別株は証券会社・口座名・口座区分を補ってください。
2. 円現金・ドル現金を入力して保存します。追加投資資金が既存現金に含まれない場合は「計上済み」のチェックを外します。
3. 残高を証券口座と照合し、「実保有・現金を確認」を押します。
4. 自分の Finnhub API キーを入力し、「Finnhubキーを保存して更新」を押します。株価と ECB の USD/JPY 日次参考レートは起動時、30分ごと、手動操作で更新します。
5. 目標配分と概算税の条件を確認し、売買計画と売買後の現金を確認します。計算可能になると CSV を保存できます。

初期配分は NVDA 15%、AVGO 10%、PLTR 30%、APP 20%、SOFI 5%、CRDO 3%、RKLB 4%、SPCX 3%、現金 10% です。PLTR の初期売却上限は 0 株で、サテライト 3 銘柄の購入は待機に設定されています。値は目標配分の画面から変更できます。目標にない既存銘柄は売却保留です。売却する場合は、その銘柄を目標比率 0% などで明示的に登録し、上限を選びます。

SpaceX の Class A 普通株式 `SPCX` は 2026年6月12日に Nasdaq Global Select Market と Nasdaq Texas で取引が始まりました。アプリでは Finnhub の発行体・取引所・通貨と価格のタイムスタンプがそろった場合に価格を利用します。未保有で確認できない場合は監視表示を続けます。保有がある場合は、株価が確認できるまで売買計画を保留します。 [SpaceX IR](https://ir.spacex.com/faqs-and-contact/) [SEC Form 10-Q](https://www.sec.gov/Archives/edgar/data/1181412/000162828026066880/spcx-20260930.htm)

## データ保護と旧機能

- 新規インストールは保有ロットなしで始まります。旧版の既知のサンプルは移行時に除外し、その他の旧ロットは確認待ちになります。
- JSON の取り込み・復元は差分を承認してから反映します。直前の V2.3 データをブラウザー内に保持します。別端末への移行や長期保管には JSON 書き出しを使ってください。JSON と CSV に資産情報が含まれるため、保管先と共有先を確認してください。
- JSONBin は利用者が許可したときに接続します。既存 Bin は読み取りと差分確認に使い、クラウドへ保存する場合は別のプライベート Bin を作ります。
- Finnhub キーはブラウザー内に保存され、Finnhub へ直接送られます。JSONBin の認証情報はリクエスト時に使います。キーはエクスポートやエラー表示に含まれません。
- ウォッチリスト、購入計画、取引履歴、市場センチメント、SPY/QQQ、保有銘柄の RSI・移動平均乖離、決算予定を維持しています。購入計画から約定を記録すると、入力内容に基づく保有ロットと履歴が作成されます。証券会社で約定した後に記録し、現金を照合してください。
- 企業評価では 2028年の弱気・標準・強気シナリオと投資仮説を手入力できます。業績指標は実績・外部予測・独自予測を分け、期間と出典を保存します。

## API制限とキャッシュ

- Finnhubの銘柄別株価は最後に取得した時刻と値をブラウザの `localStorage` に保持し、直近30分のページ再読み込みでは原則として再取得しません。最大32銘柄を1回のバックグラウンド更新対象とし、追加分は後続の更新で取得します。
- ECB公表のUSD/JPY日次参考レートは、原則60分以内はブラウザに保存したデータを再利用します。レートの基準日・株価時刻の有効性チェックは従来どおりです。キャッシュがあっても古い価格を最新として扱いません。
- FinnhubがHTTP 429を返したら、`Retry-After`（指定がなければ最低60秒）を保存し、画面の再読み込みや別タブからも停止時刻までは新しいFinnhubリクエストを送りません。
- 株価・為替の「更新」ボタンとFinnhubキーの保存操作ではキャッシュのTTLを無視して再取得します。ただし429の停止期間中は再試行しません。頻繁な連続更新は避けてください。
- SPY・QQQの補助指標は成功時2時間、失敗時1時間、決算予定は最大4銘柄を2時間ごとに取得します。RSIなどYahoo公開プロキシを使う参考指標は失敗時6時間の再試行抑制をかけ、1回に最大2銘柄に抑えます。
- 外部公開プロキシの403/CORS/502はFinnhubの429とは別の問題です。取得元の正式な利用条件が確認できない指標を、キャッシュ機能だけで取得できるようにはなりません。
- APIキー・口座データ・取引履歴はこの価格キャッシュには含みません。保有情報の保存形式も変えません。

## テストと仕様

```sh
npm ci
npm test
npx playwright install chromium
npm run test:browser
```

ブラウザーテストには Python 3 が必要です。インストール済み Chromium を使う場合は `PM_CHROMIUM=/path/to/chromium npm run test:browser` が使えます。PC・スマホともテスト中の価格・保有・認証情報は架空です。
