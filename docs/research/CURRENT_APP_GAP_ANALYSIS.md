# 既存アプリの現状とギャップ分析

作成日：2026-11-27／対象：main（`a529c5d` 以降、PR #45 まで）／作成者：Claude（調査・設計のみ。コード変更なし）

判定の区分：
- **正常（実機確認済み）**：本番でオーナーが操作して確認した、または本番スモーク・実データで確認した
- **正常（テストのみ）**：自動テストでは確認済みだが、本番で実際に使った確認はまだ
- **改善余地あり**／**一部実装**／**未実装**／**不明（要実機確認）**

コードがあるだけでは「正常」としない。

## 3. ギャップのまとめ

最も大きな不足は、**判断の根拠を数字で検証する仕組みがないこと**です。
- 市場シグナルも参入シグナルも「投資判断」も、閾値やルールの表示にとどまっている。過去にどうだったか（件数・分布・下落幅）を示していない
- そのため「VIX30で買うべきか、待つべきか」「段階買付のB日を前倒しすべきか」に、アプリが根拠を返せない

逆に、次の土台はすでに揃っている。
- 修正版の財務データ
- 予想の表示（コンセンサス・ガイダンス・自分の想定）
- 固定ルールを守る売買計算
- 段階買付と今日やることガイド

新しい機能は、ゼロから作らずにこれらにつなげるのがよい。
