# 買い場・売り場モデルの研究仕様

作成日：2026-11-27／区分：**設計提案**（このファイルに書く仕様・閾値はすべて検証前の仮説。事実として扱わない）

## 0. 基本方針

0. **データ**：最初の段階は FRED の VIXCLS（1990〜）・NASDAQ100（1986〜）・NASDAQCOM（1971〜）・USD/JPY で行う（個人・非商用の利用に限る。生データは公開リポジトリに入れない。`COMPETITOR_FEATURE_AUDIT.md` §5）
1. **最初に答える問いを1つに絞る**：「VIXが30を超えた直後に買うのと、正常化を待つのと、段階的に買うのでは、どれが有利か（円建て・税・機会損失込み）」
2. **対象は指数・ETFから**（SPY・QQQ、必要に応じて ^NDX・^GSPC）。個別株の全銘柄検証は、上場廃止銘柄を含むデータがないと生存バイアスが避けられないため後回し（データの可否は `COMPETITOR_FEATURE_AUDIT.md` §データ）
3. **確率は「事象・期間・件数」とセットで出す**。「買い確度80%」とは書かず、例えば「VIX≥30の初日から60営業日以内に、QQQが+10%に先に到達した割合 9/14（64%、95%信頼区間 39〜84%）」と書く
4. **最初はルールと条件別統計**。機械学習は、独立したイベントの数が十分になってから検討する（§4）
5. 結果は**段階買付（A/B/C日）と「今日やること」に参考情報として出す**。自動売買・自動の配分変更はしない

## 1. 市場レジーム判定（ルールベース・説明可能）

| 軸 | 指標（日次終値） | 区分（仮説） |
|---|---|---|
| トレンド | QQQ終値と200日移動平均の位置、50日線の20日変化 | 上昇／下落／横ばい |
| ボラティリティ | VIX水準と過去5年の中での位置（パーセンタイル）、20日実現ボラ | 低／通常／高／極端（VIX≥30） |
| 期間構造 | VIX ÷ VIX3M | <1：通常（コンタンゴ）、≥1：逆転（ストレス）。VIX3Mは2009-09-18以降のみ（Cboe CSV。保存の規約に注意）→ この軸を使う集計は件数が少ない |
| 下落の深さ | 直近52週高値からの下落率 | 0〜−10%／−10〜−20%／−20%超 |
| 参考（検証に使わない） | CNN Fear & Greed | 長期の履歴が取れないため表示のみ |

出力：
- 現在のレジーム
- **同じレジームだった過去の日**からの 20／60／250営業日後のリターン分布（中央値・下位5%・最大逆行幅）、件数、期間
- 重なりが大きい連続日は「独立した局面の数」も併記（例：該当 412日／独立局面 9回）

## 2. イベント研究：VIX≥30

### イベント定義（仮説）
- **発生日 t0**：VIX終値が30以上になった最初の日（直前20営業日は30未満）
- 同じ局面の重複を避けるため、t0から60営業日以内の再発は同じイベントとする

### 比べる買い方（約定は**シグナル翌営業日**。最初の段階で使うFREDの系列は終値のみのため、**翌営業日の終値**で近似する。判定に使った終値と同じ終値では約定しない。始値のあるデータに移ったら翌日始値に変える）
| 戦略 | 内容 |
|---|---|
| S1 即時 | t0翌日に全額 |
| S2 段階（現行と同じ比率） | t0翌日 50%、+10営業日 30%、+20営業日 20%（間隔は感度分析で変える） |
| S3 正常化待ち | VIXが20を下回った翌日に全額（期限 120営業日。来なければ期限日に買う） |
| S4 下げ止まり確認 | t0以降、QQQが直近安値から+X%反発し、かつ VIX/VIX3M<1 に戻った翌日 |
| S0 基準 | イベントに関係なく毎月同額（ドルコスト平均） |

### 評価指標（各イベント × 各戦略）
- t0基準で揃えた 60／120／250営業日後の**円建て**リターン（USD/JPYの同日レートで換算）とドル建て
- 購入後の最大逆行幅（MAE）・最大順行幅（MFE）
- **機会損失**：待っている間に上がった分（S3・S4 の約定価格 ÷ S1 の約定価格 − 1）
- 下位5%のリターン（CVaR 5%）、最大ドローダウン
- 手数料（0.495%・上限22ドル）と為替スプレッドの控除後
- 戦略間の差の**ブートストラップ信頼区間**（イベント単位で再標本化）

### 注意（結果に必ず添える）
- VIX≥30の独立イベントは数十回にも満たない可能性が高い（**件数はデータ取得後に確定**）。差が統計的に有意にならない場合は「差があるとは言えない」と表示する
- 1回の極端な局面（2008年、2020年3月）が結果を左右する。各イベントの個別結果の表を必ず出す
- 指数での結果は、PLTR・APP・NVDAのような高ボラ個別株にそのまま当てはまらない

## 3. セリングクライマックス（検証可能な仮説として）

市場全体の騰落数・上昇/下落出来高（90% Downside Day 等）は、無料で長期履歴を安定して得られないため、**指数・個別銘柄の自分の価格と出来高だけで作れる定義**から始める。

候補定義 SC-1（仮説）：
- 出来高 ÷ 50日平均出来高 ≥ 2.0（相対出来高）
- 当日の値幅 ÷ ATR(14) ≥ 1.5
- 終値位置 CLV = ((C−L) − (H−C)) ÷ (H−L) ≥ 0（安値から戻して引けた）
- 52週高値から −15%以下
- RSI(14) ≤ 30（前日まで）
- 確認：その後5営業日以内に当日安値を割らない

検証：SC-1の翌営業日始値で買った場合の 5／20／60営業日後のリターン分布を、条件を満たさない同程度の下落日（対照群）と比べる。閾値は**学習期間で決め、検証期間で一度だけ確認**する（後から閾値をいじらない）。

## 4. 確率モデルの比較（採否の判断）

| 手法 | 位置づけ | 判断 |
|---|---|---|
| 条件別の過去統計（＋ブートストラップ） | 件数が少なくても解釈できる | **採用（最初）** |
| ロジスティック回帰 | 少数の特徴量で確率を出す。係数が説明できる | 採用候補（P1）。日次の重なりに注意 |
| Triple Barrier（上側・下側・期限の先着） | 目的変数の定義として有用 | **目的変数として採用**（§5） |
| 確率較正（Calibration） | 出した確率が実際の頻度と合うかの確認 | 確率を出すなら必須 |
| LightGBM／XGBoost | 非線形・多特徴量 | 対象外（当面）。独立イベントが少なく過学習のリスクが大きい |
| Meta-Labeling | 一次シグナルに賭けるかを学習 | 対象外（当面）。一次シグナルの有効性の確認が先 |

## 5. 目的変数（例）

- R20／R60／R250：20／60／250営業日後のリターン（翌日始値→各日終値）
- TB(+10%, −10%, 60日)：60営業日以内に +10% と −10% のどちらに先に触れたか（触れなければ「期限」）
- MAE60：60営業日以内の最大逆行幅
- Q05：リターン分布の下位5%

## 6. 売り場モデル（買いの裏返しにしない）

| 判断 | 入力 | 出力 |
|---|---|---|
| 投資仮説の悪化 | 四半期トレンドの出口シグナル（既存）、ガイダンス未達、自分の想定との乖離 | 「仮説が崩れた条件」に該当したかのチェック表 |
| 集中の解消 | 固定配分との乖離、PLTR下限 | ③の売買案（既存）にそのまま反映 |
| 乗り換え | 売る銘柄の税引後の手取り、買う銘柄の期待リターン（自分の想定ベース）、税で失う額 | 「乗り換えで取り戻すのに必要な超過リターン」＝ 税額 ÷ 税引後手取り（例：取得額比+50%の含み益を税率20.315%で確定すると時価の約6.8%が税になり、乗り換え先が約+7.3%余分に上がって初めて同額に戻る） |
| 下落リスク回避 | レジーム（§1）、個別銘柄のMAE分布 | 参考表示のみ（自動の売却提案はしない） |

## 7. 検証の作法

- **ウォークフォワード**：例）1999〜2009で閾値を決め、2010〜2016で確認、2017〜で最終確認（期間はデータの開始日で確定）
- **先読みの禁止**：その日の判定には当日終値までのデータのみ。約定は翌営業日始値
- **Purged CV と Embargo**：60営業日先を見る目的変数は期間が重なるため、学習と検証の境目で前後60営業日を除く（ロジスティック回帰を使う段階で適用）
- **データスヌーピング対策**：試した条件の数を記録し、結果と一緒に表示する
- **生存バイアス**：指数・ETFのみを対象にする段階では問題にならない。個別株に広げる場合は上場廃止銘柄を含むデータが必要（有料）

## 8. 画面での見せ方（案）

- 市場分析：現在のレジーム ＋「過去の同じ状態から60営業日後」の分布（箱ひげ）と件数
- 研究結果ページ：戦略ごとの比較表（中央値・下位5%・機会損失・件数・信頼区間）、イベントごとの個別結果、累積損益とドローダウンの図
- 今日やること・段階買付：「現在 VIX 32（逆転中）。過去の同局面では、即時と待機の差は ±x%（有意差なし）」のような1行の参考情報
- すべての数字に：データ期間、件数、約定の前提、手数料・為替の扱い、限界の注記
