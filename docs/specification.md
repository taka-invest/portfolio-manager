# データ構造と計算仕様

## 保存データ

ブラウザーの `pm_workspace_v3` に、バージョンを含む一つの JSON オブジェクトを保存します。JSON バックアップは同じ形式です。価格と為替の取得結果は実行中のメモリーに保持します。別タブの変更を検知した場合、保存と売買計算を保留し、再読み込みを案内します。

| フィールド | 内容 |
|---|---|
| `version` | 保存形式のバージョン。V2.3 は `3` |
| `positions` | 一意 ID、ティッカー、証券会社、口座名、口座区分、資産種別、株数・口数、取得単価、取得通貨、ロット全体の円取得原価、参考単価、監視区分、メモ |
| `targets`・`cashTarget` | ティッカー別の比率・コア／サテライト区分・購入待機・売却上限と、現金の目標比率。売却上限 `null` は上限なし、`0` は売却保留 |
| `cash` | 円現金、ドル現金、円建て追加資金と、追加資金が既存現金に計上されているかの指定 |
| `confirmed` | 利用者による保有ロット・円現金・ドル現金の確認。保有や現金の変更、取引の記録、取り込みで確認待ちに戻る |
| `tax` | 概算税率と損益通算の試算条件 |
| `plans`・`trades`・`watchlist` | 購入計画、取引履歴、監視銘柄。旧版の計画進捗と市場スナップショットを含む |
| `company` | ティッカー別の投資仮説、仮説が崩れる条件、3シナリオ、業績・評価の指標 |
| `preferences` | テーマ、表示通貨、比較基準日、開閉設定と互換用の旧閾値 |

企業評価の指標は、指標名、入力区分（実績・外部予測・独自予測）、対象期間、値・単位を含む内容、出典、基準日を持ちます。対象は売上成長率、GAAP EPS、調整後 EPS、営業利益率、フリーキャッシュフロー、会社ガイダンス、アナリスト予想、Forward P/E、2028年想定 EPS です。V2.3 では手入力で管理し、決算予定は Finnhub から取得します。

### 移行・復元

旧版は `pm_positions`、`pm_plans`、`pm_trade_log`、`pm_watchlist` と設定用の各キーを localStorage に保存します。ローカルの旧 JSON は保有配列、JSONBin は主に `positions` と `plans` を保存していました。取り込みファイルに含まれていない旧履歴・設定は V2.3 側の値を使います。IndexedDB の旧保存先は「旧ファイル保存先を確認」から読み込める場合があります。

既知の初期サンプルはティッカー・株数・円建て取得単価で照合します。旧版はサンプルにもランダムな ID を持たせ、現在値を更新したため、ID と現在値は照合に用いません。サンプルと株数・取得単価が一致する実保有がある場合は、口座情報を添えて手動登録します。編集済みの旧ロットは要確認として取り込みます。旧版で米ドル取得単価を円に変換して保存したデータは、保存済みの円値を引き継ぎます。元のドル単価を保持している場合はロット編集で補います。

確認画面で承認した後に保存し、上書き前の V2.3 は `pm_workspace_v3_previous` に置きます。現行保存が破損している場合は、承認を得て `pm_workspace_v3_invalid` に元の文字列を保持してから復元します。旧版の localStorage や外部ファイルは読み取り専用です。

## 市場データ

- 株価は Finnhub `quote` の `c`（USD）と `t`（供給元タイムスタンプ）を用います。保有銘柄と目標・購入計画・ウォッチリスト上の銘柄を重複排除して取得します。
- 取引開始直後の15分は直近営業日の終値を許容します。米国取引時間中は当日かつ90分以内、引け後と休場時は直近営業日の通常終値・短縮終値の15分前以降の値を使います。米東部時間と標準の祝日・短縮取引日を考慮します。取引所が将来発表する臨時休場はカレンダーの更新が必要です。 [Nasdaq 取引カレンダー](https://www.nasdaq.com/holidayandtradinghours)
- 為替は Frankfurter の ECB 指定 API で取得した USD/JPY 日次参考値です。基準日は供給元の公表日で、欧州の営業日と休日を反映します。当日の公表待ちとしてベルリン時間 18 時までは前営業日を許容します。 [Frankfurter](https://frankfurter.dev/) [ECB 参考為替レート](https://www.ecb.europa.eu/stats/policy_and_exchange_rates/euro_reference_exchange_rates/html/index.en.html)
- 必須価格・為替が欠損、期限切れ、直近の更新で通信失敗となった場合は計画と CSV を停止します。以前取得した値や旧版の手入力価格は、評価表に参考として表示することがあります。未保有で購入待機中の銘柄と未確認の SPCX は、価格待ちの監視行として残します。429 を受けたら連続取得を中断し、最低60秒、読める場合は供給元指定の再試行時刻まで待ちます。

## リバランス

- 対象は資産区分が米国個別株のロットです。積立NISA投信・その他除外ロットは評価額、取得原価、損益、配分、売買、税の対象外です。NISA 口座の米国個別株は配分対象です。
- 円株価はドル株価 × USD/JPY。株式評価額は円株価 × 保有数量の合計です。対象資産は株式評価額 + 円現金 + ドル現金 × USD/JPY + 未計上の追加資金です。目標評価額は対象資産 × 銘柄別目標比率。目標株数は目標評価額 ÷ 円株価です。
- 超過額を株価で割って整数株の売却上限を求め、銘柄別設定と売却可能口座でさらに制限します。口座は登録順で選び、ロット別の内訳を表示します。課税口座で円取得原価が不足する口座と、税の扱いを特定できない口座区分は売却を保留します。
- 概算譲渡損益は、売却株数 ×（円株価 − 同銘柄・同口座内の平均円取得原価）です。口座の決算・税計算と一致するとは限りません。税率の初期値は20.315%です。通算なし、同一課税口座での通算、同一年度で対象口座間の要件を満たす場合の通算を比較できます。NISA 株の売却益・損は課税損益と通算から除きます。各計算グループの概算税を円単位で切り上げます。既存の年間損益、配当、繰越控除、手数料、スプレッド、外国税、各口座の実際の源泉徴収・後日の還付は試算外です。 [国税庁 1463](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1463.htm) [国税庁 1474](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1474.htm) [国税庁 1535](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1535.htm)
- 利用可能現金は開始現金 + 売却代金 − 概算税。税引き後総額 × 現金目標比率を取り置き、残額の範囲で不足額の大きい銘柄から整数株を買う試算です。サテライトの購入待機に設定された銘柄には資金を配分しません。円・ドルは一つのプールとして扱い、税は円優先、購入はドル優先で不足分を参考レートで換算する前提です。実際の決済・口座間移動は利用者が管理します。
- 売買後の評価額は更新前と同じ株価、売買後比率の分母は対象資産 − 概算税で計算します。CSV は UTF-8 BOM 付きで、金額と株数の符号は買いが正、売りが負です。
