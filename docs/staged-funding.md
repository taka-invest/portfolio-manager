# PLTR資金調達型・3段階買付（V2.7）

## 固定条件
- 第1弾：買付予算 **5,000,000円**
- 第2弾：買付予算 **3,000,000円**
- 第3弾：買付予算 **2,000,000円**
- 対象：NVDA 15% / AVGO 10% / CRDO 3%。保有株数を先に引き、3銘柄の不足額を算定する。
- 原資：PLTR特定口座の株式を売却し、概算譲渡所得税・売却手数料控除後に各予算を調達する。
- **PLTR比率30%の下限**：対象個別株＋投資対象現金の**税・売却手数料控除後**の額を分母として判定する。30%を割る売却株数は提案しない。
- 長期的な現金10%目標は**本モードの売買制約に適用しない**（通常リバランスの現金10%設定を変更しない）。
- 売却代金で調達できる金額・購入対象の不足額・予算のうち一番小さい額までを買い付ける。未使用額は現金に残す。

## 計算方法
1. APIで時価とUSD/JPYを取得。USDJPYはLive-Ratesの時刻付きスポット中値を優先し、使えなければExchangeRate.funの時間更新レートを試す。最終フォールバックのECB/Frankfurter日次値は**売買計算には使用せず**、表示の参考にとどめる。
2. 全個別株・投資に充当する円と米ドルの現金の時価を計算する。積立NISAの投資信託と対象外資産は算入しない。
3. PLTR特定口座の平均取得原価・概算税率・推定手数料から、整数株売却後の資金を試算。30%下限を維持できる最大売却株数を二分探索する。
4. その範囲で「今回の固定予算を概ね調達する最小整数PLTR株数」を求める。不足する場合は不足額を警告表示する。
5. 税・手数料控除後の対象資産額に対する3銘柄の目標配分を再計算し、不足額の割合で整数株へ配分する。
6. 買付手数料を差し引いて予算を超えない整数株を表示する。株価・為替が動けば計算結果も動く。

## 注意点・実行手順
- 発注は行わない。注文保証ではなく参考試算。米国株の滑り、売買手数料の割引、税額の年内損益通算、証券会社の為替適用レートや預り金の拘束で結果が異なる。
- モデル手数料は**片道0.495%、上限22 USD**。証券会社で実際の売買手数料・税額・買付可能金額を必ず照合する。
- 第1弾の実際の約定後は**保有ロット（PLTR減株、NVDA/AVGO/CRDO増株）および円・ドル現金**を証券会社の最新残高に合わせて更新し、「実保有・現金を確認」を実施してから第2弾を選択する。第3弾も同様。
- 第1弾の**参考予測を第2弾の既成事実にしない**。第2弾・第3弾はその時の保有実績、時価、為替、残りの目標不足額から独立に再計算する。
- 現行の「3段階の選択」はブラウザーに保持する表示上の進捗であり、**購入が約定した証拠ではない**。確定記録は取引ログと保有ロットで行う。
- PLTRがすでに30%未満の場合は売却0株と警告する。下限による不足予算はPLTRを追加売却して埋めない。
- 日次ECBレートしか取れない場合、保有・現金が未確認の場合、株価が古い/欠けている場合は売買数量を出力しない。
