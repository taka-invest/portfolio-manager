# CNN Fear & Greed Index

## 取得元と運用開始の条件

指標の提供元は CNN Business です。指定の `https://production.dataviz.cnn.io/index/fearandgreed/graphdata` は公開ページが利用する非公式エンドポイントです。実装時の直接リクエストは HTTP 418 で自動アクセスを拒否されました。CNN の利用規約は自動収集を制限し、コンテンツの再配布にも制限を定めています。出典表示は利用許諾の代わりになりません。 [CNN Business](https://www.cnn.com/markets/fear-and-greed) · [CNN 利用規約](https://edition.cnn.com/terms)

CNN の自動取得と公開 GitHub リポジトリでの配信について許諾があり、アクセス可能な配信 URL が確認できた場合に、リポジトリの **Settings → Secrets and variables → Actions → Variables** で以下を設定します。

| 変数 | 値 |
|---|---|
| `CNN_FG_DATA_AUTHORIZED` | 許諾を確認後に `true` |
| `CNN_FG_APPROVED_URL` | CNN が利用を許諾した HTTPS URL。指定のエンドポイントを使う場合はその URL |

未設定時は定期処理をスキップし、アプリには「公開データなし」と CNN へのリンクを表示します。PR のテストでは架空データを使用します。

## 定期更新と復旧

デフォルトブランチにワークフローが入った後、GitHub Actions は月〜金の 23:23 UTC に動きます。日本時間では火〜土の 08:23、米東部時間では 18:23（標準時）または 19:23（夏時間）です。許諾と変数の設定後に Actions の **Refresh Fear & Greed → Run workflow** で初回取得を確認できます。GitHub Actions の実行開始には遅延が生じることがあります。

検証済みのデータは専用の `market-data` ブランチに `fear-greed.json` として保存されます。アプリはそのファイルを起動時・定期更新時・手動更新時に読みます。データの更新が Pages の再デプロイを必要としない設計です。取得失敗やデータ形式変更では、エラー種別と取得試行時刻を更新し、直前の正常データを参考値として保持します。古い時点への巻き戻りを検知した場合も同様です。

## 表示と鮮度

- スコア、5段階の分類、前営業日・1週間前・1か月前の比較値とポイント差を表示します。比較値は CNN の各比較フィールドを使用し、欠損はダッシュで示します。
- CNN のデータ基準日時と更新試行日時を日本時間で表示します。グラフは表示できる履歴を30・90・365日で絞り込みます。
- 米東部時間18時を過ぎても直近の取引日の値がなければ「古いデータ」と表示します。週末や米国市場休場日は直近の営業日を基準に判定します。
- 最新の取得に失敗した値、期限切れの値はグラフ・比較の参考に表示し、センチメントのシグナルや取引履歴の新規スナップショットへの採用は保留します。VIX と VXN は個別に更新します。このページは投資判断の補助表示です。

## 旧版で「取得中」が残る理由

3つの外部プロキシが失敗した場合、応答が存在しないまま `fgRes.ok` を参照していました。例外を空の catch で受けていたため、エラー表示へ変わりませんでした。旧コードは有効なスコア0も除外し、履歴の代替値に日時フィールドを参照していました。新しい処理は検証済みの公開 JSON を読み、失敗時にも画面の状態を更新します。
